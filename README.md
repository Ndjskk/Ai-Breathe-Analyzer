# AI Breath Analyzer - 3D Showcase

Files: index.html, style.css, script.js, server.js, package.json

Run:
1. Install Node.js (https://nodejs.org)
2. In this folder: `npm start`  (or `node server.js`)
3. Open http://localhost:3000 in Chrome or Edge and click "Play with voice-over"

Needs internet once for three.js (loaded from cdnjs in index.html).
Voices in the dropdown come from your browser/OS.
